# OwnChat

一款极简的自用 AI 聊天客户端，纯前端实现，无需后端服务。

## 特性

- **纯前端运行** — 所有数据存储在浏览器 localStorage，无需服务器
- **兼容 OpenAI API** — 支持任何 OpenAI API 格式的服务（官方、第三方、自部署）
- **流式输出** — 实时逐字显示 AI 回复，支持思考过程（reasoning）展示
- **Markdown 渲染** — 代码高亮、表格、任务列表等完整支持
- **多会话管理** — 创建、切换、重命名、删除对话
- **参数调节** — 每个对话可单独设置 Temperature、Top P、Max Tokens
- **文件上传** — 支持图片和多种文档格式
- **深色/浅色主题** — 自动跟随系统偏好，也可手动切换
- **移动端适配** — 响应式布局，手机端可正常使用

## 使用

1. 打开 `index.html` 即可运行（可直接本地打开，也可部署到任意静态服务器）
2. 首次使用会显示配置页面，填入：
   - **Base URL** — API 服务地址（如 `https://api.openai.com/v1`）
   - **API Key** — 密钥，仅保存在浏览器本地
   - **模型** — 从服务获取可用模型列表后选择
3. 点击「开始聊天」即可使用

## 技术栈

- 原生 HTML + CSS + JavaScript，无框架依赖
- 单文件架构（`index.html` / `style.css` / `app.js`）
- 数据持久化基于 localStorage
